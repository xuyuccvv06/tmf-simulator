# 交易行為紀錄介面 V1

## 檔案與使用方式
`trade_journal.html` 是獨立的手機優先交易行為紀錄頁，不覆蓋既有 `index.html` 或其他歷史回放版本。直接以支援 IndexedDB、localStorage 與檔案下載的現代瀏覽器開啟。

可建立交易、追加交易前觀察/進場/持倉管理/出場/事後回顧事件，也可保存不屬於單筆交易的一般盤面觀察。每筆交易以唯一 trade_id 串接。

## 本機儲存
- 事件紀錄以追加事件方式保存在瀏覽器 localStorage；原始事件不直接覆寫。
- 行情資料集以 IndexedDB 分塊保存，避免把大量 K 棒塞入 localStorage。
- 附件原始檔保存在 IndexedDB。
- 資料只在目前裝置與瀏覽器保存，不會自動同步到 GitHub 或雲端。
- 清除瀏覽器網站資料、使用無痕模式或瀏覽器清理儲存空間，可能造成資料遺失；請定期匯出完整備份。

## 匯入與匯出
- 「完整備份」包含事件紀錄、已載入行情資料集及附件原始檔。
- 匯入前會檢查備份格式、事件 ID、損益欄位、修正/作廢引用、行情 OHLCV 與附件資料。
- 相同 entry_id 且內容完全相同的事件會去重；相同 ID 但內容不同會拒絕匯入。
- 匯入採 localStorage 與 IndexedDB 分階段寫入；若 IndexedDB 寫入失敗，會嘗試回復先前的事件紀錄。
- 匯入不是雲端同步或多裝置合併服務；請保留原始備份檔。

## 行情資料
- 可載入符合 canonical schema 的標準化 TMFR1 CSV。
- CSV 欄位、時間遞增、商品/週期一致性及 OHLCV 邏輯會在保存前驗證。
- 行情回看只顯示已保存資料與使用者關聯的時間區間，不自動推導交易結構或訊號。
- TMFR1 是近月連續序列，不等同個別月份合約；5 分 K 不可當成 1 分 K 或逐筆資料。

## 損益統計
- 出場事件輸入已扣除手續費與交易稅後的實際淨損益（TWD）。
- 統計區間為本週、本月、半年及今年，依出場行情時間歸屬；沒有行情時間時使用紀錄時間。
- 未完成交易不納入；作廢出場不納入；損益修正以追加修正事件保留稽核軌跡。
- 勝率分母不計入打平交易。

## 已知限制
- 尚未連接 Supabase 或其他後端資料庫，沒有帳號登入、多裝置同步或多人並行寫入。
- 瀏覽器本機儲存仍受裝置空間、瀏覽器政策與使用者清除資料影響；完整備份是必要的防護措施。
- 自動化測試可驗證純統計/事件邏輯及程式語法；仍需在實際 iPhone Safari/Chrome 裝置確認檔案下載、IndexedDB 容量、觸控縮放與長時間使用。
