# 交易行為紀錄介面 V1

## 檔案
`trade_journal.html` 是獨立的手機優先交易行為紀錄頁。它不覆蓋既有 index.html 或其他舊版回放網站。

## 使用方式
直接以瀏覽器開啟此 HTML。可建立交易、追加事前觀察/進場/持倉管理/出場/事後回顧事件，也可保存不屬於單筆交易的一般盤面觀察。每筆交易以唯一 trade_id 串接。

## 儲存與備份
- 目前使用瀏覽器 localStorage，資料只在目前裝置與瀏覽器保存，不會自動同步到 GitHub 或雲端。
- 使用「匯出備份 JSON」定期備份。
- 可匯入相同格式備份；匯入時依 entry_id 去重。
- 清除瀏覽器網站資料可能造成本機資料遺失。

## 目前限制
- 尚未連接 Supabase 或其他後端資料庫。
- 行情資料關聯欄位目前僅保存使用者提供的 reference，前端尚未載入 TMFR1 CSV，也不會驗證 SHA 或精確 K 線時間。
- 附件上傳、截圖預覽、多人同步及帳號登入尚未實作。
- 事件流程檢查是紀錄管理，不代表交易規則或策略判斷。
