# 交易行為紀錄 V1

## 目的
先忠實保存交易者實際看盤、判斷、執行與回顧的描述。此模組不預先定義 FVG、HH/HL、流動性掃除、趨勢或進場條件，也不把自由文字自動轉成交易規則。

## 事件類型
- `pre_trade`：交易前觀察與想法
- `entry`：實際進場與當下理由
- `management`：持倉期間的管理與判斷
- `exit`：出場行為與原因
- `post_trade`：事後回顧
- `observation`：不屬於單筆交易的盤面觀察

## 紀錄原則
- 保留原始敘述，不自動修正文句或推導規則。
- `recorded_at` 是寫入紀錄的時間；`market_timestamp` 是描述所指向的行情時間，兩者分開。
- 可選的 context 只保存交易者自行填寫的描述，不代表已驗證的數學條件。
- JSONL 採追加方式保存；相同 entry_id 重送不重複寫入，已存在 ID 不允許改寫成不同內容。
- 後續分析必須標示哪些是原始紀錄、哪些是研究者整理、哪些已經過統計驗證。

## 後續流程
先累積真實紀錄，再與使用者一起整理常見判斷與行為模式。只有使用者確認後，才提出候選量化描述；候選描述仍須獨立回測，不可把觀察樣本直接當成績效證明。
