# TMF 資料來源與限制

- 商品識別：TMFR1 為微型臺指近月連續合約序列，不等同個別月份合約，也不可與 MXF/TXF 混用。
- 微型臺指期上市日：2024-07-29；上市前資料不得標記為真實 TMF。
- 不補造缺失 K 線、不以其他商品代替 TMF。
- 連續合約換月接縫、調整方式與回溯偏差必須在每次研究報告揭露。
- 每份資料應保存來源、下載時間、時區、欄位定義、篩選條件及 SHA-256。

既有資料稽核摘要（沿用先前研究紀錄，非本次重新驗證）：2024/2025 原始資料共 552,600 列；上市前資料及合成資料排除後，完整交易時段正式資料記錄為 397,905 列，另有 540 列終端不完整時段。正式回測前必須重新執行稽核並保存報告。
