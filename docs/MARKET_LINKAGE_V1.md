# 行為紀錄與行情資料關聯 V1

## 目的
讓每一則交易行為紀錄可回到確切的 TMFR1 資料版本與 K 線時間，不做最近時間猜測、不補 K、不改寫行情，也不推導結構規則。

## 關聯欄位
- `dataset_id`：資料集登錄識別碼
- `dataset_sha256`：資料集內容雜湊，固定資料版本
- `timeframe`：資料週期，例如 5m
- `start_timestamp` / `end_timestamp`：欲檢視的行情時間窗，必須對齊資料內實際存在的 K 線時間

## 解析規則
1. 資料集 ID 與 SHA-256 必須同時相符。
2. 時間戳採 ISO-8601，保留時區資訊。
3. 起訖時間必須精確對應資料內 K 線，不做四捨五入或 nearest-bar。
4. 若沒有資料、邊界不存在或資料版本不符，明確報錯，不猜測、不補值。
5. 關聯只是把使用者的紀錄定位到行情，不代表該行情已被解讀成任何結構或訊號。

## 與行為日誌的搭配
行為日誌可保存此 reference 物件，讓事前觀察、進場、持倉管理、出場及事後回顧都能指向相同的資料版本。截圖與錄影仍以附件方式保存；後續 UI 再提供檔案上傳與預覽。
