# TMF Research Platform — 初始架構

## 原則
- Python 負責確定性資料驗證、撮合假設及統計計算。
- AI 僅提出假設、研究與反方審查；不可自行將推測寫成績效。
- 正式策略結論須經資料稽核、樣本外驗證及人工批准。

## 本版範圍
本版只建立資料模型、OHLC/時間序列驗證及簡化的 next-bar-open 模擬器骨架。不是完整交易平台或正式撮合引擎；尚未處理同根 K 停損停利衝突、跳空成交、部分成交、交易時段、換月及完整費率表。

## 開發流程
在獨立開發分支開發，通過測試與人工檢查後才透過 Pull Request 合併；不直接覆寫既有網站 HTML 或 CSV。
